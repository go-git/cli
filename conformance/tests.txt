#   the base bytes from the pack at the base's offset and does not fall
#   back to a loose copy of the base when the in-pack base is unreadable.

#   Concrete repro (blob_2 is a delta against blob_1, blob_1's pack header
#   is corrupted, a loose copy of blob_1 has been written):

#     gogit cat-file blob <blob_2> → exit 1 (pack reader needs blob_1's
#                                   content for the delta; reads it from
#                                   the pack, fails on the corrupt header,
#                                   does not retry via the loose store)
